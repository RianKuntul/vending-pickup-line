One pickup line, 200 characters at most, that a vending machine would use on
a passing human — entry for the make.fun contest "One Line, One Minute: The
Vending Machine Pickup Line Contest" ($2 prize, 10 paid places).

`main.ts` (Node 22) writes the line to `/output/entry.txt`
(`$MAKEFUN_OUTPUT_DIR` when set, for local runs).
